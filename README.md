## Возможности
- Геолокация при первом запуске (при отказе — ввод города)
- Прогноз: сегодня + 2 следующих дня
- Добавление ещё 2 городов (с автодополнением, валидацией)
- Кнопка «Обновить» делает новые HTTP-запросы (без перезагрузки страницы)
- Сохранение выбранных локаций в localStorage, восстановление после перезапуска

## Технологии
- HTML + CSS + чистый JavaScript (ES Modules)
- API: Open‑Meteo (forecast + geocoding)
